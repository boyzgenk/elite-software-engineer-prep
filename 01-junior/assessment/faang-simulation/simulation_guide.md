## 🎯 Simulation Execution Guide

### Pre-Simulation Setup
1. **Environment Preparation**
   - Quiet, professional space
   - Stable internet connection
   - Go development environment ready
   - Whiteboard or digital drawing tool

2. **Mindset Preparation**
   - Review company values and culture
   - Practice coding in interview setting
   - Prepare STAR stories for target company
   - Get adequate rest and nutrition

### During Simulation
1. **Technical Rounds**
   - Think aloud throughout problem-solving
   - Start with brute force, optimize iteratively
   - Write clean, commented Go code
   - Test thoroughly with edge cases

2. **System Design Rounds**
   - Clarify requirements upfront
   - Start high-level, drill down systematically
   - Discuss trade-offs and alternatives
   - Include Go-specific implementation details

3. **Behavioral Rounds**
   - Use STAR method consistently
   - Provide specific, quantified examples
   - Align stories with company values
   - Show progressive leadership growth

### Post-Simulation Analysis
1. **Performance Review**
   - Detailed scoring across all criteria
   - Specific feedback on improvement areas
   - Comparison with L3/L4 expectations
   - Readiness assessment for real interviews

2. **Improvement Plan**
   - Targeted practice recommendations
   - Timeline for addressing weak areas
   - Mock interview scheduling
   - Final readiness validation
