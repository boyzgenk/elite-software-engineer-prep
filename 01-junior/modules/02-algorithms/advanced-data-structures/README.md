## 📚 Learning Modules

### 🌳 [AVL Trees](./avl-trees/)
**Self-Balancing Binary Search Trees**
- Theory: Balance factors, rotation algorithms, height management
- Implementation: Complete AVL tree in Go with insertion, deletion, search
- Applications: Database indexing, in-memory caches, balanced data storage
- **Time Complexity:** O(log n) for all operations
- **Space Complexity:** O(n) storage, O(log n) recursion stack

### 🔴 [Red-Black Trees](./red-black-trees/)
**Balanced BST with Color Properties**
- Theory: Red-black properties, rotation rules, color maintenance
- Implementation: Complete red-black tree with color-aware operations
- Applications: Language runtime implementations (Java TreeMap, C++ std::map)
- **Time Complexity:** O(log n) for all operations
- **Space Complexity:** O(n) storage, O(log n) recursion stack

### 📊 [Segment Trees](./segment-trees/)
**Range Query Optimization**
- Theory: Tree construction, lazy propagation, range operations
- Implementation: Segment tree for range sum, min/max queries
- Applications: Competitive programming, real-time analytics, time series data
- **Time Complexity:** O(log n) query/update, O(n) build
- **Space Complexity:** O(4n) ≈ O(n) storage

### 🔢 [Fenwick Trees](./fenwick-trees/)
**Binary Indexed Tree for Prefix Operations**
- Theory: Binary representation, prefix sum calculation, range updates
- Implementation: Fenwick tree with point updates and range queries
- Applications: Frequency counting, order statistics, range sum queries
- **Time Complexity:** O(log n) query/update, O(n log n) build
- **Space Complexity:** O(n) storage

### 🌲 [Trie Structures](./trie-structures/)
**Prefix Trees for String Processing**
- Theory: Trie construction, prefix matching, compressed tries
- Implementation: Standard trie, compressed trie, suffix trie
- Applications: Autocomplete, spell checkers, IP routing tables
- **Time Complexity:** O(m) insert/search (m = string length)
- **Space Complexity:** O(ALPHABET_SIZE * N * M) worst case

### 🎯 [Bloom Filters](./bloom-filters/)
**Probabilistic Membership Testing**
- Theory: Hash functions, false positive rates, optimal parameters
- Implementation: Bloom filter with configurable hash functions
- Applications: Web caches, database query optimization, distributed systems
- **Time Complexity:** O(k) insert/query (k = hash functions)
- **Space Complexity:** O(m) bits (m = filter size)
